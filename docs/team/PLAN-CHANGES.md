## 保留的必做工作

可编辑三维场景、至少一个真实 API 生成物件、云保存、编辑权和版本冲突保护、AI 提案确认与撤销、不可变发布、手机查看与撤销分享仍是必做项。公共库、内置和生成模型分别标明来源；已有五款缓存素材不等于已实现按需求调用公共库推荐。

## 执行假设与排期

- “输入平面图”按上传图片、人工标定和描边拆分；自动识图、CAD 解析和自动三维重建未被明确要求。
- “多边形矩形”按矩形或简单单层多边形解释，覆盖凹多边形样例；坐标和入口锚点在 S01 冻结。
- 建议演示 16 人、4 组，仍须满足不超过 50 物件；现有 100 人体育馆原型不能直接视为符合这一演示约束。
- 原 48 小时排期没有单列新增功能。补齐任务不代表时间自动足够；G0 根据真实接入情况调整，C 记录团队决定，不悄悄删除必做项。

## 当前代码与计划的距离

核对时远程仓库是 HTML/JavaScript/Three.js 静态原型，尚无 Next.js 应用结构、账号后端或协作任务包。A01 需验证指定底座的接入方式；S01 冻结实际目录边界。保留现有原型作参考，不能把计划中的技术栈写成已实现功能。
