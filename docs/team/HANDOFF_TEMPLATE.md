# 单任务交接报告模板

复制为 `reports/<角色>/<任务ID>.md`，路径相对本任务包。AI 每完成一个任务或遇到必要阻塞时交付，B 汇总状态。示例占位内容应全部替换；不要把模板当证据。

```markdown
# A03 交接报告
- 负责人：A / 实际成员姓名
- 状态：review（或 in_progress / blocked）
- 目标仓库与分支：
- GitHub Issue：
- Pull Request：
- 实际版本/提交：
- 预览/部署入口（若有）：
- 评审人（B 的代码由 A 评审）：
- 契约版本：
- 时间与测试环境：

## 本次完成
- 可观察行为：
- 修改/生成文件：
- 运行入口与命令：

## 验收证据
| 验收条目 | 方法/步骤 | 实际结果 | pass/fail/blocked/not_run | 证据路径 |
|---|---|---|---|---|

## 尚未完成和阻塞
- 未通过条目：
- 缺少的输入/环境：
- 需要谁提供什么：
- 仍可继续的独立工作：

## 下一位接手
- 接收角色与任务 ID：
- 可直接使用的文件/接口/场景 ID：
- 一条最小使用示例：
- 已知限制与注意事项：
```

报告随对应任务 PR 提交到 `docs/team/reports/<ROLE>/<TASK_ID>.md`。PR 描述用 `Refs #编号` 关联任务，合并本身不证明实际验收完成；B 根据依赖和证据更新 TASKS.json。缺少真人测试、账号接入或真实网络证据时如实保留 blocked/not_run。
